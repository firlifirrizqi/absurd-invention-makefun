# One-Sentence Absurd Invention Pitch

One ridiculous invention, pitched in a single sentence, written for the [Make.fun bounty](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a).

`main.py` writes the pitch to `/output/entry.txt`:

> My Wi-Fi router faints dramatically every time someone says 'the internet is slow', and only revives once you apologise to it out loud.

Run it with `python3 main.py`.
